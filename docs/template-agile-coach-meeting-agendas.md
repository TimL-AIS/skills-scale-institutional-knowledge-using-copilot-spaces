# Agile Coach Meeting Agendas

## Purpose
Provide structured agendas for key meetings facilitated by the Agile Coach to ensure effective ceremonies and continuous improvement.

---

## Sprint Retrospective Agenda

**Duration:** 45-75 minutes (adjust based on team size and sprint length)  
**Attendees:** Development team, Product Owner, Scrum Master, Agile Coach (facilitator)  
**Frequency:** End of each sprint

### Agenda

**1. Opening (5 minutes)**
- Welcome and state the retrospective goal
- Review retrospective working agreements (e.g., Vegas rule, focus on improvement)
- Brief recap of sprint goals and outcomes

**2. Set the Stage (5 minutes)**
- Quick check-in: One word to describe how you felt about the sprint
- Reminder: psychological safety and constructive feedback

**3. Gather Data (15 minutes)**
- What went well? (Successes, wins, positive moments)
- What could be improved? (Challenges, pain points, frustrations)
- Interesting observations or learnings

_Techniques: Timeline, mad/sad/glad, start/stop/continue, etc._

**4. Generate Insights (15 minutes)**
- Group similar themes
- Discuss root causes of challenges
- Identify patterns across sprints
- Celebrate successes and understand what enabled them

**5. Decide What to Do (15 minutes)**
- Brainstorm improvement actions
- Prioritize 2-3 actionable items
- Assign owners and due dates for each action
- Define success criteria

**6. Close (5 minutes)**
- Recap action items and owners
- Quick feedback on the retrospective itself
- Appreciation round (optional)

**7. Follow-up**
- [ ] Document action items in project tracking system
- [ ] Share retrospective summary with team
- [ ] Add action items to sprint backlog
- [ ] Review progress on previous action items in next retro

## Sprint Planning Facilitation Agenda

**Duration:** 2-4 hours (depends on sprint length)  
**Attendees:** Development team, Product Owner, Scrum Master, Agile Coach (facilitator)  
**Frequency:** Start of each sprint

### Agenda

**1. Opening (10 minutes)**
- Review sprint goal and objectives
- Confirm team capacity and availability
- Review Definition of Done

**2. Part 1: What (60-90 minutes)**
- Product Owner presents prioritized backlog items
- Team asks clarifying questions
- Team discusses and confirms sprint goal
- Team selects backlog items they can commit to

**3. Break (10 minutes)**

**4. Part 2: How (60-90 minutes)**
- Team breaks down selected items into tasks
- Team estimates effort and identifies dependencies
- Team confirms commitment is realistic
- Identify risks and mitigation strategies

**5. Close (10 minutes)**
- Finalize and communicate sprint goal
- Review sprint board setup
- Confirm next ceremonies (standup, review, retro)
- Address any final questions

**6. Follow-up**
- [ ] Document sprint goal and committed items
- [ ] Update sprint board
- [ ] Share sprint plan with stakeholders
- [ ] Set up sprint tracking and metrics

## Team Health Check Agenda

**Duration:** 30-45 minutes  
**Attendees:** Development team, Agile Coach (facilitator), optional: Scrum Master, Project Manager  
**Frequency:** Monthly or as needed

### Agenda

**1. Opening (5 minutes)**
- Purpose: assess team health and identify support needs
- Confidentiality and psychological safety reminder

**2. Health Check Survey (10 minutes)**
_Use anonymous survey or physical cards for these dimensions:_

| Dimension | Red (Poor) | Yellow (Ok) | Green (Great) |
|-----------|------------|-------------|---------------|
| Team collaboration | | | |
| Work-life balance | | | |
| Clarity of goals | | | |
| Autonomy | | | |
| Tools and processes | | | |
| Learning and growth | | | |
| Value delivered | | | |
| Fun at work | | | |

**3. Discussion (20 minutes)**
- Review results and identify trends
- Discuss areas of concern (reds and yellows)
- Celebrate strengths (greens)
- Identify root causes and improvement opportunities

**4. Action Planning (10 minutes)**
- Define 1-2 actions to address concerns
- Assign owners and timeframes
- Schedule follow-up check

**5. Close (5 minutes)**
- Thank team for candid feedback
- Commit to addressing concerns
- Schedule next health check

**6. Follow-up**
- [ ] Share summary with team and leadership (anonymized)
- [ ] Track action items
- [ ] Monitor progress on improvements
- [ ] Report trends to leadership if escalation needed

## Coaching 1-on-1 Agenda

**Duration:** 30 minutes  
**Attendees:** Individual team member, Agile Coach  
**Frequency:** Bi-weekly or monthly

### Agenda

**1. Check-in (5 minutes)**
- How are you doing overall?
- Any immediate concerns or wins to share?

**2. Progress Review (10 minutes)**
- Review progress on previous goals or action items
- Discuss challenges or obstacles encountered
- Celebrate successes and learning

**3. Coaching Topic (10 minutes)**
_Focus on one topic based on individual's needs:_
- Agile practices or techniques
- Team collaboration or conflict resolution
- Career development or skill building
- Specific challenge or situation
- Preparation for upcoming role or responsibility

**4. Action Planning (5 minutes)**
- Define next steps or commitments
- Set specific, measurable goals
- Identify resources or support needed
- Schedule follow-up or check-in

**5. Follow-up**
- [ ] Document key insights and action items (confidentially)
- [ ] Share relevant resources or materials
- [ ] Check in on progress before next session
- [ ] Adjust approach based on individual needs

## Impediment Resolution Meeting Agenda

**Duration:** 30 minutes  
**Attendees:** Relevant stakeholders based on impediment, Agile Coach (facilitator)  
**Frequency:** Ad-hoc as needed

### Agenda

**1. Opening (5 minutes)**
- State the impediment clearly
- Explain impact on team and project
- Set meeting objective (decision, action plan, escalation)

**2. Analysis (10 minutes)**
- Review impediment context and history
- Identify root causes
- Discuss previous attempts to resolve
- Clarify ownership and accountability

**3. Solution Brainstorming (10 minutes)**
- Generate possible solutions
- Evaluate feasibility and impact
- Identify resources needed
- Determine decision-makers

**4. Action Planning (5 minutes)**
- Agree on resolution approach
- Assign owners and deadlines
- Define success criteria
- Plan communication to affected parties

**5. Follow-up**
- [ ] Document decision and action plan
- [ ] Update team on resolution progress
- [ ] Monitor implementation
- [ ] Close out impediment when resolved
- [ ] Capture learning for future prevention

## Notes on Facilitation Best Practices

### General Tips
- Start and end on time
- Ensure everyone has a voice
- Park off-topic items in a "parking lot"
- Focus on actionable outcomes
- Follow up on commitments
- Continuously improve meeting effectiveness

### Agile Coach Responsibilities
- Remain neutral and objective
- Guide the process, not the content
- Ask powerful questions
- Foster psychological safety
- Ensure time-boxing is respected
- Help team self-organize and problem-solve
- Model agile values and principles
