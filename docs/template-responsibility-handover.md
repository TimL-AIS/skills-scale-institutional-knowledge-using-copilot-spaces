## Handover Checklist

### Knowledge Transfer
- [ ] Scheduled handover meeting(s) with incoming person
- [ ] Walked through current work in progress
- [ ] Reviewed key stakeholders and communication channels
- [ ] Explained tribal knowledge and context
- [ ] Reviewed tools and access requirements
- [ ] Shared important documents and resources
- [ ] Discussed risks and mitigations

### Administrative
- [ ] Updated project documentation with new role owner
- [ ] Transferred access permissions where needed
- [ ] Updated stakeholder contact lists
- [ ] Notified team and stakeholders of handover
- [ ] Scheduled check-in meeting for 1 week after handover
- [ ] Created transition plan with timeline

### Shadowing Period (if applicable)
- [ ] Incoming person attended key meetings as observer
- [ ] Incoming person paired on critical activities
- [ ] Incoming person has direct access to ask questions
- [ ] Established mentor/support period (duration: _[timeframe]_)
